# LocalVideoStatio Android MVP

This repository contains a minimal but complete Android project scaffold for the LocalVideoStation app.

## Overview

- Local video discovery from MediaStore
- Home dashboard with recommendation cards
- Search, favorites, and viewing history screens
- Video detail and rating flow
- Media3-based player screen
- Room database for persistent metadata

## Build

```bash
./gradlew assembleDebug
```

## CI

GitHub Actions workflow runs the Android debug build automatically on pushes and pull requests.
